🤖  Exploring AI/LLMs and their integration into real applications

I'm a Computer Science (AI) student who enjoys building software that is both **practical and well-engineered**. My primary focus is **Java backend development** — designing and building REST APIs, working with Spring Boot and Spring Security, managing data with Hibernate/JPA, and connecting services through clean, maintainable code.

I also work on the frontend side with **React**, which gives me a full-stack perspective on how products come together. Alongside this, I've been exploring **AI and Large Language Models**, including prompt engineering and how to bring these capabilities meaningfully into applications.

I believe in writing **clean, purposeful code** — not just code that works, but code that others can read, extend, and trust. I'm actively looking for roles where I can contribute, learn from experienced teams, and grow as a software engineer.
